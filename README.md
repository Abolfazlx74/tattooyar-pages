# تتویار (Tattooyar) 🎨✨

استودیوی سه‌بعدی و بلادرنگ برای شبیه‌سازی و تست طرح‌های تتو بر روی مدل‌های آناتومیک بدن انسان با پشتیبانی از وب‌سایت استاتیک گیت‌هاب پیجز (GitHub Pages).

🌐 **مشاهده آنلاین روی GitHub Pages**:
👉 **[https://aboifazi.github.io/tattooyar-pages/](https://aboifazi.github.io/tattooyar-pages/)**

---

## 🚀 ویژگی‌ها

- **گالری طرح‌های تتو آماده و باکیفیت**:
  - ۱۶ طرح برگزیده در دسته‌بندی‌های مختلف (گرگ هندسی، اژدهای ژاپنی، جمجمه و رز، مار کبرا، ماندالای عرفانی، شیر سلطنتی، رز سیاه، شاپرک جمجمه‌ای، قطب‌نمای وایکینگ، خنجر و افعی، خورشید و ماه کیهانی، عقاب اوج‌گیرنده، بازوبند مائوری تریبال، ققنوس آتشین، ماهی کوی ژاپنی، عقاب شکارچی).
  - امکان جستجو و فیلتر بر اساس دسته‌بندی.
  - بدون نیاز به آپلود و بک‌اند؛ لود مستقیم و آنی در مرورگر.
- **استودیو سه‌بعدی ۳۶۰ درجه**:
  - مدل‌های سه‌بعدی تفکیک‌شده (دست راست/چپ، پای راست/چپ، سر، نیم‌تنه، بدن کامل).
  - حالت پروجکشن استاندارد و حالت تطبیقی انحنای عریض (UV Multi-channel).
  - پیش‌نمایش در لحظه لمس پوست (Real-time Skin Touch).
- **کنترل‌های فیزیکی ترنسفورم**:
  - اسلایدرهای فیزیکال با نمایش درصد زنده و انیمیشن شیب هنگام درگ.
  - تنظیم مقیاس (Scale)، چرخش (Rotation) و زاویه نورپردازی استودیو (Light Angle).
- **سازگاری کامل موبایل و دسکتاپ**:
  - پشتیبانی از چرخش و لمس چندگانه روی گوشی و تبلت با محافظ چرخش افقی (Landscape Lock).

- **Vite 8**
